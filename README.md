# Order Issue Resolution prototype

Customer-facing clickable prototype for Harry's order issue resolution. All orders, addresses, store availability, and resolution outcomes shown here are fictional.

The site source is [`outputs/project-choir-prototype.html`](outputs/project-choir-prototype.html). The GitHub Pages workflow publishes that same file as the site's `index.html` whenever a change is pushed to `main`. Keep editing the source file and push changes to update the shared URL.

The **Other** path opens an email draft to Harry's Customer Care. The visitor must send that email from their own email app. This prototype does not submit order resolutions.
